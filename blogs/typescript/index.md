# TypeScript

TypeScript เป็นภาษาโปรแกรมที่ถูกพัฒนาโดย Microsoft ขึ้นมาเพื่อเพิ่มความเข้าใจใน JavaScript และเพิ่มความสามารถในการพัฒนาโปรแกรมให้มีประสิทธิภาพมากขึ้น
อีกทั้งช่วยลดความผิดพลาดในการเขียนโปรแกรมด้วยความช่วยเหลือจากการตรวจสอบชนิดของข้อมูลในระหว่างการพัฒนาโปรแกรม
